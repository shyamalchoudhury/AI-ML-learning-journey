# 📊 Data Visualization with Python

This folder contains my learning journey in **Data Visualization using Python**, focusing on two popular libraries: **Matplotlib** and **Seaborn**.

My goal is to understand how to visualize data, identify patterns, explore distributions, and communicate insights effectively through graphs and charts.

## 📚 Libraries Covered

### 1. Matplotlib
[Matplotlib](https://matplotlib.org/) is a Python library used to create static, animated, and interactive visualizations.

**Topics covered:**
- Line plots
- Bar charts
- Multiple bar charts
- Scatter plots
- Histograms
- Box plots
- Plot customization
- Titles, labels, legends, and grid lines
- Figure size and layout
- Saving plots as image files
- Working with X-axis labels and ticks
- Plot styles and formatting

### 2. Seaborn
[Seaborn](https://seaborn.pydata.org/) is a Python visualization library built on Matplotlib. It makes it easier to create attractive statistical visualizations.

**Topics covered:**
- Line plots using `sns.lineplot()`
- Bar plots using `sns.barplot()`
- Scatter plots using `sns.scatterplot()`
- Histograms and distribution plots
- Box plots using `sns.boxplot()`
- Using `hue` to differentiate categories
- Understanding statistical distributions
- Visualizing data spread and outliers
- Understanding skewness and data distribution
- Customizing plot appearance
