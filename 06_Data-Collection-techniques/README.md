
# 📊 Data Collection — Popular Techniques

## 1. Public Datasets

- **Kaggle:** Datasets for data analysis, machine learning, and practice.
- **UCI Machine Learning Repository:** Datasets for ML experiments and research.

## 2. Databases

- **SQLAlchemy:** SQL toolkit and ORM for connecting to databases.
- **SQLite3:** Built-in Python library for SQLite databases.
- **PyMySQL:** Connects Python applications to MySQL.
- **PyMongo:** Connects Python applications to MongoDB.
- **Py2neo:** Python library for interacting with Neo4j graph databases.

## 3. APIs

- **APIs:** Retrieve structured data from web services.
- **JSON:** Common format for exchanging structured data.
- **XML:** Tag-based format for storing and exchanging structured data.
- **Requests:** Sends HTTP requests and retrieves API responses.
- **BeautifulSoup:** Can parse XML responses when appropriate; it is generally unnecessary for JSON APIs.

## 4. Web Scraping

- **BeautifulSoup:** Extracts information from HTML and XML documents.
- **lxml:** Parses HTML/XML and supports XPath.
- **Selenium:** Automates browser interactions.
- **Playwright:** Automates browsers and handles dynamic web pages.
- **Requests:** Fetches web page content for parsing.
