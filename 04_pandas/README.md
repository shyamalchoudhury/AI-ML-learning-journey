## 🚀 My Learning Approach

I believe in learning through practice rather than memorising syntax alone.

My approach is to:

1. Understand the underlying concept.
2. Implement it through code.

4. Debug errors and learn from mistakes.
5. Document useful concepts and revisit them.
6. Apply what I've learned in progressively larger projects.
